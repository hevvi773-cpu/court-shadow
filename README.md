#  宫廷暗影 · Court Shadow

> 一个 1v1 身份博弈 × 宫廷经济的小游戏原型。每人手握一套「宫廷工资表」，自选一名角色当恶魔，互猜对方的恶魔，在「躺平当恶魔」和「攒工资复利」之间反复拉扯。

- 🎮 网页原型：`court-shadow.html`（单文件，浏览器 / 手机浏览器直接打开即玩）
- 📐 规则文档：`court-shadow-rules.md`
- ☁️ 在线试玩：`https://520263ad76e74faaa3ff8fa79e27df1f.app.workbuddy.link`

## 一、怎么玩（30 秒上手）

1. 双方各有一套相同的角色工资表：**国师 3 / 国王 4 / 王后 3 / 王子 1 / 公主 1**。
2. 每局各自**自愿**选 1 个角色当**恶魔**（该角色本局工资 = 0，隐藏）。
3. **天使**在对方看不到的范围内随机落到某个非恶魔角色，该角色本局工资 **×2**。
4. 结算：恶魔(0) + 天使×2 + 普通人×1 → 累加进各自的金币。
5. 双方互相**猜对方这局的恶魔**：
   - 猜中 → 拿走**对方天使本局工资的一半**（因为恶魔本身没金币，奖励从其天使身上拿）；
   - 猜错 → **无惩罚**。
6. 结算后：本局是天使／普通人的角色，下局工资 **×2（复利）**；恶魔角色工资**冻结不变**。
7. 共 **5 局**；**最后一局（第 5 局）王子 / 公主（未成年人）不可当恶魔**。

## 二、核心机制：工资体系（已用举例验证）

| 角色 | 基础工资 | 说明 |
|---|---|---|
| 国师 | 3 | —— |
| 国王 | 4 | 价值最高 |
| 王后 | 3 | —— |
| 王子 | 1 | 未成年人 |
| 公主 | 1 | 未成年人 |

**举例（来自设计讨论）**
- 本局：国师 = 恶魔(0)，公主 = 天使(1×2=2)，国王 4，王后 3，王子 1 → 本局进账 `4+3+1+2`。
- 下局工资变为：国师 **3**（冻结，因为是上局恶魔）、国王 **8**、王后 **6**、王子 **2**、公主 **2** —— 完美吻合 「3，8，6，2，2」。

> 设计要点：恶魔角色工资被「冻结」，避免长期当恶魔反而滚起雪球；非恶魔角色持续复利，制造「这局当恶魔吃亏、下局要补回来」的张力。

## 三、设计思考过程（我的）

> 这部分是从最初一个梦，到最终规则的推导记录。原文整理自设计讨论。

### 1. 灵感：一个梦
最开始只是一个模糊的设定——五个宫廷角色（国师 / 国王 / 王后 / 王子 / 公主），其中一个被选为「恶魔」，恶魔没有金币；另有「天使」随机出现、金币翻倍；如果恶魔身份被猜中，对方拿走一半金币。本质上我想要的是「身份隐藏 + 经济博弈」的对抗感，不是一个纯运气游戏，而是让每一局的选择都有代价和权衡。

### 2. 角色为什么要分高低压？
五个角色不是平权的：国王 / 国师 / 王后工资高，王子 / 公主工资低（兼作「未成年人」概念）。高低差制造了博弈张力——你舍不得把高价值角色拿去当恶魔（因为要损失工资），但又想拿它去赌「对方猜不到」。

### 3. 最核心的矛盾：「恶魔没金币」vs「被猜中拿一半金币」
这是规则里最别扭的一点。恶魔本局工资是 0，那「被猜中拿走一半金币」该拿谁的钱？
- 第一版直觉是「拿走恶魔的一半」，但恶魔没钱可拿，逻辑塌了。
- 解决方案：改成**「猜中对方恶魔 → 拿对方天使本局工资的一半」**。天使是真正产出金币的角色，从它身上抽成，既保留了「猜中有人付出代价」的爽感，又绕开了「恶魔零金币」的死结。这是整个规则里最关键的一次妥协。

### 4. 工资复利：让「长期选择」有意义
光靠单局猜测太单薄。于是加了复利：非恶魔角色每局后 ×2，恶魔冻结。
- 这样「一直当恶魔」会让你偏离复利曲线，「一直当普通人」又能滚雪球——恶魔和天使共同构成「风险 / 收益」的取舍。
- 恶魔冻结防止「混子」靠长时间当恶魔反而攒出高额工资。

### 5. 指认失败要不要惩罚？
最早没明说。后来明确：**猜错无惩罚**。理由很简单——如果没有惩罚，玩家才更愿意去赌、去博弈，游戏更轻松、更少卡顿，也更适合休闲对战。

### 6. 最后一局限制未成年人
王子 / 公主工资低，若放任他们在最后一局当恶魔，等于「低价值角色躺平收尾」破坏平衡。所以只在**最后一局**禁止未成年人当恶魔，既保留前面局的灵活性，又堵住收尾漏洞。（是否首局也禁，还在待定列表里。）

### 7. 界面：梦到的样子
我想到的不是表单，而是**翻牌**：双方各 5 张角色卡，点一下翻开看身份；最上面一串金币数，最下面一行记录前几轮的天使 / 恶魔是谁。这种「翻开揭晓」的瞬间感，才是这个游戏的味道。

## 四、规则演化对照表

| 原始设想 | 最终实现 |
|---|---|
| 五角色选一个做恶魔 | 每人各自从自己一套里选 1 个当恶魔（自愿自选） |
| 恶魔没有金币 | 恶魔角色本局工资 = 0 |
| 天使金币翻倍 | 天使本局工资 ×2 |
| 天使/普通人下局工资翻倍 | 非恶魔角色每局后 ×2（复利） |
| 恶魔工资不变 | 恶魔角色工资冻结 |
| 被猜中恶魔 → 对方拿一半金币 | 改为「猜中对方恶魔 → 拿对方天使本局工资的一半」 |
| 指认失败 | **无惩罚** |
| 首局 / 末局未成年人不能当恶魔 | 未成年人 = 王子/公主；**仅在最后一局**禁止当恶魔 |

## 七、待拍板（仍可调整）

1. 互猜奖励：现在是「对方天使本局工资一半」。要不要改成「对方总资产一半」或「对方该天使角色的产出」？
2. 是否也要在**第一局**就禁王子 / 公主当恶魔（不只最后一局）？
3. 复利滚雪球较快（5 局后国王 / 王后可上百），要不要给工资设上限？
4. 角色技能：要不要给国王免疫误判、国师偷看对方 1 项等独特被动？
5. 小程序化：是否继续补全微信小程序版本？
